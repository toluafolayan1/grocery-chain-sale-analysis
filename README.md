# Grocery Chain Sales Analysis Dashboard

## Overview
An end-to-end data analytics project analyzing grocery chain sales data 
using Microsoft SQL Server and Power BI.

**Prepared by:** Tolu Afolayan  
**Period:** 2026  
**Dataset:** 1,955 rows | Source: Kaggle  

---

## Tools Used
- Microsoft SQL Server (SSMS)
- Power BI Desktop

---

## Project Workflow
1. Data Collection — Downloaded from Kaggle
2. Data Import — Loaded into SQL Server
3. Data Cleaning — Nulls, duplicate
4. Exploratory Data Analysis — 27 SQL queries
5. Data Visualization — Power BI dashboard

---

## SQL Analysis Covered
- Aggregations (SUM, AVG, COUNT)
- Window Functions (RANK, DENSE_RANK, LAG)
- CTEs (Common Table Expressions)
- Date functions (DATEDIFF, DATENAME)
- Data cleaning and standardization

---

## Key Insights
- 🏪 **Top Store:** GreenGrocer Plaza with revenue of $9,880.76
- 🛒 **Top Aisle:** Personal Care with revenue of $8,289.12
- 📅 **Peak Month:** March with revenue of $7,988.54
